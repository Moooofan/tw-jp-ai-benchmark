I.M.P.U.L.S.E. 策略公關方法論

AI PR 的核心不是「用 AI 寫公關稿」，而是用公關方法管理品牌在人類與 AI 兩個資訊環境中的形象資產：人要看得見、聽得懂並願意相信；AI 也要能取得、理解並引用可靠證據。

本次 Lite 範圍涵蓋四個來源：Google Trends 觀察台灣品牌搜尋，OpView 觀察台灣公開聲量，ximu 觀察指定 AI Security 題組中的 AI 回答位置，is-Agentic 檢查官網在單一任務下能否讓 Agent 取得第一方資訊。四者量尺不同，僅做交叉判讀，不合併成市場占有率。

案例佐證｜供應商競逐 Agent Security

Agent 安全已從概念進入產品組合競爭，差異化必須落到可驗證能力。

Palo Alto Networks 於 2026 年 3 月發布 Prisma AIRS 3.0，主張涵蓋 Agent 的探索、風險評估、身分與執行期防護；Cisco 於 2 月擴充 AI Defense，加入 AI BOM、MCP Catalog 與即時 guardrails；Fortinet 於 8 月透過收購 Virtue AI 強化 Agent red teaming、治理與即時防護。三家都以全生命週期與治理為主軸，因此僅使用「完整平台」已不足以形成唯一辨識，還需要產業情境、部署證據與技術邊界。官方發布可證明各家公開定位，不等於產品效能已由獨立第三方驗證。

AI DECISION READING

& AGENT READINESS

官網基本可讀，但 Agent 完成任務時仍大量繞向搜尋與第三方來源。

is-Agentic 以單一任務測試 www.paloaltonetworks.com：要求 Agent 說明公司做什麼、服務誰。總分 72／100，評語為可用但仍有數個實質缺口。這反映網站資訊取得條件，不是 Palo Alto Networks 的產品能力分數。

ANALYZE 證據承接與可讀性

第一方內容應讓 Agent 更快完成「理解、比較與驗證」。

測試顯示 Agent 可以到達網站，核心內容亦可取得；但導航的容錯、結構化產品資訊、API 說明與缺頁回復仍影響任務效率。Agent 最後透過 24 個步驟、9 個推理步驟與 5 次搜尋完成回答，評估備註指出結果高度依賴搜尋與第三方來源。
